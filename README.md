# Basalt
Common libraries and nodes for ROS2 swarm robotics.

Abstraction of pertinent modules of [Aphelion](https://github.com/Noe-Sanchez/Aphelion) and [tello_vicon](https://github.com/Noe-Sanchez/tello_vicon) with support for HITL in [Eredin](https://github.com/Noe-Sanchez/Eredin) and visualization in [Luminol](https://github.com/Noe-Sanchez/Luminol).
